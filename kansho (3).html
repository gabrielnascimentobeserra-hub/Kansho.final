    Sobre o Kanshō

    O que é

    Kanshō (鑑賞, “apreciar”) é um agregador de avaliações de animes. Em vez de abrir três sites para comparar notas, você vê as notas do IMDb, do MyAnimeList e do AniList lado a lado e uma única média por anime, que alimenta o ranking de Mais votados.

    O diferencial: uma média justa

    Uma média simples engana: um anime com 300 votos e nota 9,8 passaria à frente de um clássico com 300 mil votos e nota 9,0. A Média Kanshō corrige isso em duas etapas:

    1. Cada nota é ajustada de acordo com o número de votos da própria fonte: quanto menos votos, mais a nota é puxada para a média geral daquela fonte.
    2. A média final é a média simples das notas ajustadas das fontes que têm nota para o anime. Se uma fonte não avaliou o título, ela é ignorada.

    nota ajustada = v/(v+m) × nota + m/(v+m) × C
    v = votos do anime · m = mediana de votos da fonte no catálogo · C = nota média da fonte no catálogo

    Exemplo com C = 8,0 e m = 100 mil votos: nota 9,8 com 300 votos vira 8,01; nota 9,0 com 300 mil votos vira 8,75. Em Configurações você pode trocar para a média simples, se preferir.

    O que você pode fazer aqui

    • Ver o ranking de Mais votados e abrir a página de cada anime com as notas de cada fonte.
    • Explorar os gêneros e usar a busca do topo para achar um título, gênero ou estúdio.
    • Criar uma conta para salvar seus favoritos e ajustar o critério da média, o carrossel e as animações.
    • Escolher seus gêneros preferidos e receber sugestões personalizadas em Para você.

    Como funcionam as recomendações

    Cada anime tem uma lista de gêneros e estilos (Ação, Fantasia, Seinen, Isekai…). Os gêneros que você escolhe em Para você valem mais; cada anime que você favorita também reforça os gêneros dele. O Kanshō compara esse perfil com todos os títulos do catálogo e ordena os que mais combinam, dando um pequeno bônus aos de nota mais alta. Animes já favoritados não aparecem, e cada sugestão mostra o motivo. Tudo é calculado no seu navegador, a partir de dados salvos apenas nele.

    Fontes e créditos

    O catálogo reúne uma seleção fixa de clássicos e até 200 dos animes mais populares e em alta no AniList, atualizados enquanto a página está aberta; o ranking é exibido de 50 em 50. Para respeitar os limites das APIs, as notas ficam em cache por 24 horas; a primeira visita leva alguns minutos para completar o MyAnimeList, e as notas aparecem aos poucos. Notas e capas vêm do AniList, do MyAnimeList (por meio de uma API não oficial) e do IMDb (por meio da API OMDb). As sinopses dos títulos acrescentados automaticamente vêm em inglês e são traduzidas para o português, de forma automática, quando aparecem nos destaques ou quando o título é aberto. Todos os dados pertencem às respectivas fontes; o Kanshō não é afiliado a nenhuma delas. Quando as fontes não respondem, o site usa as últimas notas salvas no navegador ou valores de exemplo, e avisa você no topo da página.

    Sobre este protótipo

    As contas, os favoritos e as configurações ficam salvos apenas neste navegador (a senha é guardada somente como hash). Para uso real, essas funções precisam de um servidor. Os trailers vêm do AniList e as notícias da página inicial, de uma API não oficial do MyAnimeList; se não carregarem, a página mostra exemplos que levam a buscas externas.
